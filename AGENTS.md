# Orientações do projeto

- Este é um jogo original da WJ Tecnologia para celular e PC. Preserve a interface em português.
- Não copie arte, mapas, áudio, texto ou código dos jogos de referência.
- Não registre credenciais de contas, códigos de recuperação, dados pessoais ou segredos no repositório.
- Mantenha regras econômicas separadas da renderização. Execute `npm test` e `npm run build` após mudanças relevantes.
- Declare claramente recursos locais, demonstrativos e ainda não implementados; não apresente o localStorage como sincronização online.
- Atualize a documentação de validação e o roadmap conforme a implementação real.
