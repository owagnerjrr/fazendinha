# Recursos da versão 0.3

Ferramenta: Image Generation integrada ao ChatGPT, modo nativo, transparência ativada. A referência de identidade foi `art-source/farmer.png` do próprio projeto. Não foi usada a CLI de geração.

Os atlas foram preservados com paleta de 256 cores em `art-source/v3/`. Os arquivos preparados ficam em `public/assets/v3/`. O script `scripts/prepare-animation-art.py` recorta quadros, alinha os pés, fixa a escala pelo chapéu e registra os pontos de saída da água.

No tools, no accessories, no farmer in the output.

## farmer-hoe

Create a production action sprite sheet of the EXACT SAME farmer from reference image (straw hat green band, chestnut hair, tan skin, cream rolled-sleeve shirt, green overalls brass buttons, brown boots, chibi face). Keep identity, clothing, proportions, crisp outlined 16-bit pixel art and colors. Output TRUE TRANSPARENT background, EXACT 4 columns x 4 rows equally spaced, complete character AND hoe in every cell, wide empty gaps. Each cell has the SAME body scale and feet baseline. The farmer uses a real farm HOE WITH TWO HANDS, wooden handle long and narrow with a flat grey steel blade attached at right angle, not a pickaxe or sword. Row1 faces DOWN toward viewer. Row2 faces LEFT. Row3 faces RIGHT. Row4 faces UP, back toward viewer. In EVERY row columns show one digging cycle: col1 ready with hoe held at waist, col2 both arms lift hoe with blade above shoulder, col3 knees and torso bend forward as both arms swing blade down to ground in front of feet, col4 recovery pulling hoe back toward waist. Vary actual arm, elbow, torso and knee pose, not just rotating an item beside an idle body. Include the tool held naturally in both hands with believable grip; no detached floating tools. All feet remain planted at the exact same relative baseline. Allow enough transparent margin for the full raised hoe so nothing crosses cell boundaries. No soil, no particles, no water, no shadow, no text, no lines, no extra characters. Orthographic top-down 3/4 RPG camera, NOT isometric. Source is style and character identity reference, NOT a background to include. This is a sprite atlas for a game, not an illustration.

Show different arm, elbow and torso positions, not just an idle farmer beside a detached can. All boots remain planted at same relative baseline. Do NOT draw any water stream or droplets: the game engine will animate the water separately. No shadow, no ground, no plants, no text, no grid lines, no extra characters.
